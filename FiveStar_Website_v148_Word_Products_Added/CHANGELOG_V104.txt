Version 104 changes
- Fixed Contact “Send us a message” phone validation so the value is normalized immediately before validation and submission.
- Applied phone normalization to dynamically rendered shared contact forms as well as the original Contact form.
- Increased the input character allowance so users can type or paste formatted numbers; separators are removed before validating the final number.
- Kept the same rules as Cart: +92 followed by exactly 10 digits, or local 03 followed by exactly 9 digits (11 total); invalid numbers show “Please correct your number.”
- Updated the public app.js cache version to 104.
- No unrelated features intentionally changed.
