Five Star Fast Food & Kashmiri Barfi — v28 mobile overlay update

Changes:
- Opening the cart hides the mobile announcement/header/navbar; closing the cart restores them.
- Mobile navigation slides in from the right.
- While the menu is open, the header branding/cart/search are hidden; the menu button remains in the top-right as a white × close button.
- Closing the menu restores the normal mobile header.
- Drawer backdrop, outside click, Escape key, and menu-link close behavior remain supported.
- Desktop styling is unchanged.

Run from the extracted project root (the folder containing package.json):
  npm.cmd install
  npm.cmd start
